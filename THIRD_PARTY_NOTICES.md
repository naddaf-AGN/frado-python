# Third-Party Scientific Data

## Dust-opacity data

File: `frado/k_average_tot.dat`

The dust-opacity data used by FRADO Python were provided
by external collaborators for scientific research.

The relevant scientific methodology and opacity calculations
are described in:

- Röllig et al. (2013), A&A, 549, A85.
- Szczerba et al. (1997), A&A, 317, 859.

These data are not covered by the BSD 3-Clause License
applicable to the original FRADO Python source code.

Redistribution rights for the opacity table have not yet
been independently established.
